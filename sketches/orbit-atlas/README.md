## Variant: Orbit Atlas

### Design stance
Show more of the complete personal system at once while keeping a strong centre.

### Key choices
- Layout: dense concentric rings plus a persistent focus panel
- Typography: compact but never below 14px for primary labels
- Color: one colour per layer; amber only for attention
- Interaction: all nodes stay visible; details appear in a floating panel

### Trade-offs
- Strong at: complete overview, understanding relationships, desktop exploration
- Weak at: visually busier; mobile needs layer tabs and more zooming

### Best for
- Users who value system comprehension nearly as much as daily focus
