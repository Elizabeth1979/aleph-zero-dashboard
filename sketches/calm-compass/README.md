## Variant: Calm Compass

### Design stance
One next action dominates; all other information is visible but visually quiet.

### Key choices
- Layout: three concentric rings around an AI-selected centre
- Typography: large labels, minimum 14px
- Color: teal Today, blue personal areas, violet system areas
- Interaction: tap a node to open a side sheet; mobile uses a bottom sheet

### Trade-offs
- Strong at: immediate focus, low cognitive load, mobile comprehension
- Weak at: fewer labels can be shown without zooming

### Best for
- Daily use when the main need is deciding what to do next
